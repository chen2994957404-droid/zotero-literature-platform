You extract measurements from ONE passage of a materials-science paper. You are given the list of sample names used in that paper; every number you report must be assigned to one of them, or to "unknown" if the passage does not say.

Return exactly one JSON object: {"measurements": [{"sample_id": "", "name": "", "value_text": ""}]}
No explanation, no markdown fences.

Rules, in order of importance:
1. Copy each number and its unit exactly as printed in the passage. A number that is not printed in this passage does not exist.
2. "sample_id" must be copied from the given list, or be exactly "unknown". Never invent a sample name.
3. Only report a measured property of a material (strength, modulus, elongation, molecular weight, temperature of a transition, healing efficiency, conductivity, viscosity, and the like). Skip page numbers, reference numbers, instrument settings, wavelengths, and amounts of ingredients used to make the sample.
4. If the passage contains no measured property, return {"measurements": []}. An empty answer is correct and useful.
