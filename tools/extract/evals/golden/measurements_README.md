# 正文数值抽取的金标（人工读原文标的）

> 2026-09-08 建。**由 Claude 逐篇通读 `parsed/full.md` 原文后手工标注**，
> 标注时**没有看过任何模型对这三篇的输出**（防止给自己判卷）。
> 用户可抽查：每条都带 `quote`，是原文里的那句话。

## 为什么要有这份

在它之前，「抽得准不准」只能靠两种办法，两种都不成立：

1. **模型互比** —— 只能看出谁跟谁不一样，看不出谁对。
   实例：同一个 `43.1 MPa`，本地模型标成 `young's modulus`，云端标成
   `tensile strength`。**至少一个是错的，而两边的自动指标都满分。**
2. **接地率**（数字在不在原文里）—— 只能挡住「编数字」，
   挡不住「数字对但性能名标错」和「漏抽」。踩坑 #137 已经栽过一次。

## 范围（**判分前先认这个，否则分数没意义**）

**只收正文（`parsed/full.md`）里的、本文自己材料的、可测量的性能。**

| 收 | 不收 |
|---|---|
| 力学（强度/模量/断裂伸长/韧性）、流变（G′/G″/黏度/松弛时间）、热（Tg/分解温度/陶瓷产率）、分子量、传感（检出限/灵敏度/选择性）、自修复效率、能量耗散 | **别人文献里的数**（引言里的对比值）· 配方投料量（wt%、g、mL）· 实验条件（升温速率、拉伸速度、频率范围）· 仪器参数 · 谱峰位置与化学位移 · 计算/拟合得到的结构参数 · 表格里的数（表格另有脚本直扫，单独评） |

**三档**（这一档决定它怎么计分）：

- `core` —— 明确的材料性能。**漏了算漏抽，抽错算错**。
- `edge` —— 边界情况（拟合参数、合成产率、相对提升幅度、填料粒径）。
  **抽到不加分，不抽也不扣分** —— 免得判据的模糊地带惩罚任何一方。
- `negative` —— **明确不该抽的**。抽到了算**硬错误**，这是这份金标最值钱的部分：
  它能测出「把别人文献的数当成本文的」这类错，而接地率对此完全失明
  （那些数字确实印在这篇 PDF 上）。

## 怎么算分

| 指标 | 算法 |
|---|---|
| 召回率 | 抽到的 core ÷ 全部 core |
| 准确率 | （抽到的 core + edge）÷ 抽出来的总条数 |
| **错标率** | 数值对、但性能名与金标不同的条数 ÷ 抽到的条数 |
| **硬错误** | 抽到 negative 的条数（越多越危险，宁可少抽） |

匹配规则：同一条 = 数值相等（相对误差 < 1%）且样品对得上。
性能名单独比 —— **数值对而名字错，是最阴的错误**，必须能单独看见。

## 这三篇是怎么挑的

| key | 为什么选它 |

| `CL2HILJ9` | 表格 0 条，**数据全在正文** —— 最能考出拆段抽取的真水平；且引言里引了三个别人的数（797.4 MPa / 73.6 MPa / 218.2 MJ/m³），是天然的 negative |
