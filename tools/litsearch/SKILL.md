# litsearch · 对抗式检索的原料通道

**一句话**：把干净的原料递到你手上，判断由你自己做。全部免费、只读、不弹窗。

## 什么时候用我

- 你要**自己跑对抗式循环**：先想 → 去取 → 读摘要 → 发现缺什么 → 再取
- 你想知道**某个词在全世界有多少篇** —— 这个数字告诉你该收窄还是放宽
- 你要顺着**引用网络**往前（后来谁做了）或往后（这方向的根在哪）摸
- 你要在花钱之前先确认**这篇是不是用户已经有了**

## 怎么用

```
python -m tools.litsearch "borosiloxane"                    # 精确检索
python -m tools.litsearch '"boronic acid" AND silanol' --limit 40
python -m tools.litsearch "borosiloxane" --since 2015
python -m tools.litsearch --abstract 10.1021/ma500632f      # 完整摘要
python -m tools.litsearch --cited-by 10.1021/cm980353l      # 前向雪球
python -m tools.litsearch --references 10.1021/cm980353l    # 后向雪球
```

MCP 上是四个不弹窗的 tool：`lit_search` · `lit_abstract` · `lit_cited_by` · `lit_references`。

## 怎么用好我（这一节比用法重要）

**① 先宽后窄，看命中总数决定下一步。**
`lit_search` 会告诉你全世界一共命中多少篇。几千篇 = 词太宽，加限定；
几十篇 = 正好，可以全捞；0 篇 = 词写错了或这个组合真没人做过（**后者本身就是结论**）。

**② 用精确语法，别写自然语言。**
我做的是「词必须真的出现在标题或摘要里」。
写 `"phenylboronic acid" AND siloxane` 有用；写「苯硼酸和硅氧烷反应的文献」没用。

**③ 判断贴题度要读摘要，别看标题猜。**
标题常常掩盖关键信息。2026-09-09 实测：一篇标题写「用于废水处理的吸附剂」的文章，
摘要里才有「二苯基硅二醇 + 对甲苯硼酸回流 12 小时，90% 产率得到八元环」——
那正是当时最关键的一条证据。

**④ 雪球是用来补盲区的，不是用来铺量的。**
先用检索把版图铺开，挑出两三篇最核心的，再对它们做前后向雪球，
看有没有漏掉的簇。对每一篇都雪球只会把上下文淹掉。

## 什么时候**别**用我

- **要一份排好序的、告诉你「先读哪几篇」的清单** → `discover`（它会拆检索式 + 雪球 +
  按「跟用户多相关」排序）。我不排序，是刻意的：排序要向量库和本地模型，
  算不出来时会静默退化成「按被引量排」（踩坑 #149），那比不排更坏。
- **搜用户自己的库** → `library_search`（更快，而且我搜的是全世界）
- **要带页码出处、能直接引用的原文片段** → `askworld`（Sciverse 全文库）
- **要正文 / 要收进 Zotero** → `getpdf`（我只给元数据和摘要，不下载不写库）
- **要读全文的某一节** → 先 `getpdf` 的 `paper_fulltext` 拿 id，再 `library_outline`
  看菜单、`library_section` 按地址取。别让我给你全文，我也给不了。

## 边界

- 数据源是 **OpenAlex**（免费、不要密钥）。它的摘要覆盖不是 100%，
  个别文献返回空摘要 —— 那是源头就没有，不是故障。
- 「库里有没有」依赖 Zotero 开着。没开时它一律标「没有」（降级，不报错），
  这时这个标记不可信。
- 我**不写任何东西**，所以在编程端和主力机上行为一致，没有机器角色限制。
