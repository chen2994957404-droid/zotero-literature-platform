# tools/ask · 库内问答

**一句话**：向**我自己的**文献库提问，中文作答并附来源。

答案**只允许基于检索到的片段**（这是「可追溯」的前提），模型不许自由发挥；
库里没有就直说没有。

## 怎么用

```
python -m tools.ask "我的库里关于自修复有什么"
python -m tools.ask                          # 不带问题进交互模式，可连续问
```

向量化（问答的前置，没有它问答只会回答「库是空的」）：

```
python -m tools.ask.vectorize                    # 增量粗层（全库轻量，定时任务跑的就是这条）
python -m tools.ask.vectorize --deep             # 增量精层（只处理精读过、还没入库的）
python -m tools.ask.vectorize --deep --rebuild   # 清空重建整个向量库
```

## 两层向量

| 层 | 从哪来 | 特点 |
|---|---|---|
| 精层 | 精读产物 `parsed/full.md` | 有版面、有图注，答得深 |
| 粗层 | Zotero 自带全文索引 | 广撒网，覆盖全库 |

## 花钱吗

问一次要调云端大模型（一次几分钱）。向量化本身用本地 `bge-m3`，**免费**。

## 跟 askworld 的分工

- `ask` → 问**我读过的**（本地向量库，答得深，只花作答那点钱）
- `askworld` → 问**全世界**（Sciverse 三千万篇全文，答得广，要密钥）
