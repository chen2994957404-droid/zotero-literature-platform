# ask 的评测

**回答的问题：答案有没有依据、引没引对来源？**（体检回答的是「能不能跑」，那是两件事。）

## 现状：**还是空的**

这是 R5 窗建的骨架，不是已经做好的评测。别把它当成「这块已经被验过了」。

## 该怎么填

几个已知答案在库里哪一篇的问题，看检索出的片段命中没有（召回），以及答案有没有超出片段（幻觉）。

## 三样东西各放什么

| 位置 | 放什么 |
|---|---|
| `golden/` | 金标输入 + 期望产出（一个案例一个文件，文件名说清它验的是什么）|
| `scorers/` | 评分器：**纯函数**，拿到产出就能打分，不需要联网也不需要真实数据 |
| `thresholds.toml` | 阈值的唯一出处 —— 别在 .py 里再写一遍数字 |

跑评测的测试写在 `../tests/` 里（`tools/ask/tests/test_evals.py`），
参照 `tools/deepread/tests/test_evals.py` 的写法。
