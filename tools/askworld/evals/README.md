# askworld 的评测

**回答的问题：带出处的回答，出处是不是真的支持那句话？**（体检回答的是「能不能跑」，那是两件事。）

## 现状：**可追溯性那一半填好了**（2026-09-01）

不调模型、不联网、秒级。比 ask 更要紧：问自己的库答错了你还能凭印象察觉，
问全世界你对这些文献一无所知，**唯一能核对的就是出处**。

验：每条证据带出处到页码 · 相关度不够的被筛掉（**宁可少给，也不要拿跑题片段
污染答案** —— 跑题片段最坏的地方是模型会硬把它编进答案，而它带着出处，
看上去比没出处更可信）· 没证据/全被筛掉时不硬答 · 检索式一律转英文（踩坑 #35）。

**还缺的那一半**：答案质量，要真调 Sciverse + 大模型，标准答案得你来判。

## 该怎么填

同 ask，但更关键 —— 本工具的全部价值就是可追溯。

## 三样东西各放什么

| 位置 | 放什么 |
|---|---|
| `golden/` | 金标输入 + 期望产出（一个案例一个文件，文件名说清它验的是什么）|
| `scorers/` | 评分器：**纯函数**，拿到产出就能打分，不需要联网也不需要真实数据 |
| `thresholds.toml` | 阈值的唯一出处 —— 别在 .py 里再写一遍数字 |

跑评测的测试写在 `../tests/` 里（`tools/askworld/tests/test_evals.py`），
参照 `tools/deepread/tests/test_evals.py` 的写法。
