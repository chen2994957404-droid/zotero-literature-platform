# tools/digitize · 图表数字化

> 你可能是被单独选中这个积木文件夹打开的，看不到项目其他部分。本文件是你的全部上下文。

## 这是什么

**论文图里的曲线/散点/柱状图 → 可用的 X-Y 数值。**

**只做一件不可再分的事。** 如果你想在这里加一个「顺便还做 XX」的功能，
那说明 XX 属于上层，不属于这里。保持这块的纯粹，是整个体系不腐坏的前提。

用户是材料方向研究者（聚硼硅氧烷/动态键弹性体），**不懂编程**。
技术决策你自己拿主意，跟他汇报用大白话。

## 职责

论文图里的曲线 → 可用的数据点。

## 对外接口

`digitize(image, ...)`

## ⚠ 最重要的一条

**必须用云端大模型**（如硅基流动的大参数量模型）。

本地 7B 视觉模型会**编造数据并声称高置信度** —— 实测它把 FTIR 光谱读成了
完美等差数列，还标 `confidence=high`。用户当时追问「那四个点是怎么选的」
才戳破。这类幻觉比报错危险得多，因为它看起来完全合理。

**任何时候都不要为了省钱把这块换成本地小模型。**

## 状态

能力可用但暂时搁置（需要云端视觉模型额度）。自测较慢，
体检默认跳过，加 `--full` 才跑。

## 谁在用它

暂无常规调用者（按需使用）。

改这里的对外接口 = 可能弄坏上面所有调用者。**改签名前先想清楚兼容性。**

## 改完必须做

```
python tools/digitize/selftest.py                # 本块自测，必须全过（慢，需本地视觉模型）
python host/doctor/health_check.py --offline     # 全局体检，确认没碰坏别人
```
自测不过就是没改完。**没有自测覆盖的新功能，等于没写。**
