# library 的金标：不是「固定的条目清单」，是**不变量**

这里刻意**没有**一份「搜 XX 应该返回 ABCD1234」的清单。

写死具体条目的话，用户删一篇、改个标题，评测就红 —— 而那种红不代表出问题。
久了就没人认真看它了，等于没有评测。

改成验这些对任何库都成立的性质（`../../tests/test_evals.py`）：

| 不变量 | 它能抓到什么 |
|---|---|
| 用一篇自己的标题去搜，必须搜到它自己 | 分词坏了、qmode 传错、编码坏了 |
| 搜一串乱码，必须返回 0 条 | 检索退化成「返回全部」（比返回 0 条更危险，因为看起来像在工作）|
| `limit=n` 就得最多 n 条 | 分页参数写反 |
| 每条都得有 key 和 title | 压平逻辑漏字段 —— 下游全靠这两个 |

要加新的金标，加的应该也是**不变量**，不是某一天的快照。
