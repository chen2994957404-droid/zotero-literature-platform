# deepread 的金标集

**这里目前是空的 —— 这是有意的。** 真正的金标不在这个目录里，而在数据里（见下）。

## 2026-09-14 起：有了绝对参照 —— 人写的范文

「高分子学人」的推送是人写的精读，我们的模板本来就在仿它。现在每篇推送按 DOI
配上英文原件后，推文原文存成 `data/curated/<id>/reference.md`（`paths.reference()`），
索引在 `data/state/golden_deepread.json`（`paths.golden_index()`）。
建法：`python -m host.wechat_import --金标`（主力机；`--只用手上有的` 不向出版商取）。

**用它比什么**：同一篇文献，我们的精读 vs 范文 —— 栏目齐不齐、每图两段有没有、
篇幅比、数字覆盖率（范文里的数在我们这有没有）。改模板 / 换本地模型都拿这个比，
不用用户逐篇打分。这些文献**照样要跑我们自己的精读**，否则没东西可比。

精读的金标不是我们造的样例，而是**用户对真实精读的好/差评价**：
他在 Zotero 打「读完」标签，在控制面板的「精读评价」卡片里评一句好或差。
那份数据存在 `data/state/evalset.json`，
**不可重建**，所以它跟着数据走、并且被版本库保护
（`tests/test_architecture.py::test_用户不可重建的数据仍在版本库里` 在守它）。

放进这个目录的应该是**另一类东西**：将来若要固定几篇「已知好」和「已知差」的
精读 HTML 用来回归测试评分器（改了 `scorers/quality.py` 之后指标不该乱跳），
那几份 HTML 放这里。目前评分器的回归靠 `tests/test_evals.py` 里的合成样例。
