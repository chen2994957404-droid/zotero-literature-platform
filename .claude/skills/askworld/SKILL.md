# askworld —— 问全世界的文献

## 什么时候用我

- 用户问「全世界有没有人做过 XX」「外面的文献怎么说 YY」
- 需要**带出处、可直接引用**的证据（标题/年份/期刊/页码），而不是泛泛的说法
- 用户自己的库里没有这个方向

## 怎么用

我是 **prompt**（要 Sciverse 密钥 + 付费大模型）。讲清代价、用户点头后：

```
python -m tools.askworld "问题" [--since 2020] [--top 10]
```

## 什么时候**别**用我

- **问的是用户自己读过的东西** → `ask`（免费得多，且答得更贴他的语境）
- **要的是一份「该读哪些」的清单，不是一段回答** → `discover`
  （它还会标出哪些已经在库里、按跟他多相关排序）
- **没配 SCIVERSE_KEY** → 别硬跑。改用 `python -m tools.discover "关键词" --openalex`（免费）
- **要精读某一篇** → 先把它导进 Zotero，再走 `deepread`

## 边界

- 我回答的依据只有检索回来的那几段原文。**检索不到就是不回答**——
  看到「没检索到足够相关的证据」时，正确做法是换说法/放宽年份，而不是让我编
- 检索式是英文的；中文问题会先被翻成英文检索式，回答里会显示实际用了什么式子
