# library —— 查证据库

**问「有没有这篇」先用 `library_db_search` / `python -m tools.library 库 XX`**：
查的是平台自己的证据库（零网络、秒回），并标出每篇手上有什么
（正文 / SI / 已解析 / 已精读 / 已结构化）。
（2026-10-13 起 Zotero 移出平台，原来查 Zotero 的那几个工具都删了。）

**读一篇的路径**：`library_outline`（菜单，全文的 2～8%）→ `library_section` 按地址取。
地址三层粒度：`s5` 一节 → `s5.p3` 长节里的一段 → `t1` 一张表（HTML 原样，合成配比几乎全在表里）
→ `f2` 一条图注。**先点段和表，别一口气点整节**（2026-09-13 定细）。

**在库里找「哪里讲到 X」**：`library_retrieve`（返回带出处的片段 + id + 地址，零成本，不调大模型）。
**顺着引用**：`library_refs`（参考文献列表，标出 已在库里、能直接读的）。

**按条件找文献**（DOI / 标题词 / 作者 / 通讯作者 / 研究团队 / 年份 / 期刊 / 手上有什么）：
`python -m tools.library 检索 …`（用户自己用的是文献库应用里的检索页，同一套）。
**研究团队**：`python -m tools.library 团队 [名字]`（名单人工查证，在 `data/state/teams.json`）。

## 什么时候用我

- 用户问「我库里有没有 XX」「手上有什么」「某个团队有哪些文章」
- 你需要某篇的 id、正文全文的某一节，好去做别的事
- 你想在花钱之前先确认这篇在不在库里、有没有 PDF

这是**唯一**一个你可以自己随便调的工具包：只读、免费、不改任何东西
（「检索 --建索引」「团队 --重建」只写可重建的索引）。

## 什么时候**别**用我

- **要一个中文的、综合多篇的回答** → 用 `ask`（我只给条目和原文，不综合）
- **要比较数值**（拉伸强度、模量、自修复效率）→ 用 `paperdb`
  （我这里的全文是没结构的大段文字，你自己从里面抠数字既慢又容易错）
- **库里没有、要去全世界找** → `discover`（找新文献）或 `askworld`（要带出处的回答）
- **要深入理解一篇**（中文图文报告）→ `deepread`（人在文献库应用里点）

## 边界

- 取不到全文的（没解析过、扫描件没文本层）如实说明原因，别当成故障
- 旧的 8 位编号（老的 Zotero 编号）照样认得，会自动换成现在的 doi_… 编号
