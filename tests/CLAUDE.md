# tests · 架构守卫 —— 给 LLM 的说明

> 你可能是被单独选中这个文件夹打开的。本文件是你的全部上下文。

## 这个文件夹是什么

**只放跨工具的架构守卫。** 它们不测功能，只测**结构**。

工具、公用件、平台自身各自的测试**不在这里**，跟着它测的东西住
（R7 窗落实 REBUILD.md 第三节的位置表）：

| 测什么 | 住在哪 |
|---|---|
| 某个工具的判据 | `tools/<t>/tests/` |
| 某个公用件的判据 | `shared/kernel/tests/` · `shared/adapters/<b>/tests/` |
| 面板 / 体检 / 常驻服务 | `host/panel/tests/` · `host/doctor/tests/` · `host/watcher/tests/` |
| **跨工具的结构规则** | **就是这里** |

`pyproject.toml` 的 `testpaths` 四个根目录都列着 —— **漏一个，那一片的测试
就静悄悄不再运行**，而 pytest 依旧全绿（踩坑 #83 那一类事故）。

## 为什么这套东西比功能测试更重要

在它出现之前，这个项目零个测试。后果是一条因果链：

> 没有安全网 → 改动有风险 → 接手的人宁可**新加一个脚本**也不改旧的
> → 脚本增殖、互相靠文件路径粘连 → 结构越来越难懂 → 更不敢改。

规则不缺 —— 宪法里早写着。缺的是**执行者**。守卫就是执行者。

## 两个文件

| 文件 | 守什么 |
|---|---|
| `test_architecture.py` | 七组守卫，见下 |
| `test_no_undefined_names.py` | 全项目静态扫 NameError（「import 成功 ≠ 代码没问题」，踩坑 #49）|

## 七组守卫

1. **数据路径只在 `shared/kernel/paths.py` 里拼装** —— 别处出现 `data/` 字面量就红。
   这条是「改一次目录布局只改一个文件」的全部保证（R6 窗真的兑现了）。
2. **依赖只能从上往下**：`host → tools → shared.domain / shared.adapters → shared.kernel`。
   外加 domain 不许碰 adapters（否则没法离线测）、**没人可以 import host**。
   另有两条同族：联网只许在 `shared/adapters/`；domain 不许有 I/O、不许知道文件在哪。
3. **工具切片的形状**（R7 窗新增，REBUILD.md 第二、三节）：
   工具不许互相 import · 七件套齐全 · `tests/` 不许是空壳 ·
   花钱/有副作用的不许暴露成 MCP `tool` · 下沉规则（`shared/` 里不许住单使用者的块）。
4. **不许再往 `sys.path` 塞项目根** —— 项目已装成包，补丁只会掩盖「其实没装好」。
5. **两台机器的分工**：每个写 Zotero 的地方都要有 `role.require_prod`，且守卫必须在函数体里。
6. **进版本库的文件只能有一个生产者** —— 生成物/缓存不许被跟踪；
   反向地，用户不可重建的 `evalset.json` 必须留在版本库里。
7. **引导脚本不许在模块顶层 import 项目包** —— 体温计不能要求你先退烧。

## 加守卫的铁律：**每加一条，故意违反一次，确认它真的会红**

这条不是形式主义。本项目已经吃过三次同一个亏（踩坑 #83，R7 窗又抓到两处）：
**目录一改名，守卫就静默地什么都不守了**，而 pytest 一直是绿的 ——
比没有守卫更糟，因为它给人「有东西看着」的错觉。

- 表里写的目录名/模块名，能从 `paths.CODE_ROOTS` 之类取就别抄第二份
- `pytest.skip` 和空转是一回事。R7 窗之前那个唯一的 `s`，
  就是「domain 环尚未建立」——它早就建立了，只是改名成了 `shared/domain`
- 还原时**别用 `git checkout --`**：会把本窗其它未暂存的改动一起冲掉（踩坑 #90）。
  先把原文读进内存，改完写回原字节

## 硬性要求：这里的测试必须全离线

不许连 Zotero、不许连 Ollama、不许调任何云 API、不许依赖 `data/` 里有数据。
理由：一个「有时候红是正常的」的测试等于没有测试 —— 人会习惯忽略它。

需要真实服务的验证走另一档：各块的 `selftest.py` 与
`python host/doctor/health_check.py`（完整档）。需要联网的测试标 `@pytest.mark.live`，默认不跑。

## 怎么跑

```
python -m pytest -q                            # 全部离线测试（含四个根目录）
python host/doctor/health_check.py --offline   # 离线档体检
```

**改完任何代码，先跑这两条。** 红了就是结构被改坏了。
