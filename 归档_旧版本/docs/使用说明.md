# 文献图文精读系统 · 使用说明

> 上传一篇 PDF 文献 → 自动生成"高分子学人"风格的中文图文精读 HTML（完整组图 + 逐图解读 + 翻译整理）。

## 日常怎么用（三步）

1. **启动服务**：双击项目根目录的 `启动精读服务.bat`，保持窗口开着（这是后台精读引擎）。
   - 确保 Docker 里的 n8n 容器在运行：`docker ps` 看到 `n8n-literature` 即可。
2. **上传 PDF**：浏览器打开 **http://localhost:5678/form/deepread-upload-001**，上传文献 PDF。
3. **取结果**：等约 3-4 分钟，精读 HTML 出现在 `workflow_data/summary/` 目录，文件名是 `<文献名>_精读.html`。用浏览器打开即可阅读（图片已内嵌，可随意移动/分享）。

## 系统组成

```
上传PDF
  ↓ (n8n 工作流：文献图文精读流)
MineRU 云端解析 PDF → Markdown + 图 + 坐标信息
  ↓ (n8n 把解析结果落地到 workflow_data/to_process/<任务>/)
watcher.py 守护脚本监听到新任务
  ↓ 按 layout.json 坐标从原PDF裁完整Figure（解决碎图）
  ↓ DeepSeek 按范式翻译重组（只做翻译解读，省token）
  ↓ 脚本确定性拼装图文 + 渲染HTML
输出到 workflow_data/summary/<文献名>_精读.html
```

**为什么分成 n8n + 守护脚本两段**：n8n 容器里没有 Python，而裁图需要 PyMuPDF。所以让 n8n 干它擅长的（解析、下载、落地），Python 守护脚本干裁图+精读。两者通过 `to_process` 目录解耦，任一环出问题都不影响另一环，更稳定。

## 目录结构

```
n8n-literature-workflow/
├── docker-compose.yml         # n8n 容器配置
├── 启动精读服务.bat            # 双击启动守护脚本
├── scripts/
│   ├── watcher.py             # 守护脚本（监听+调度）
│   ├── deepread_v4.py         # 精读生成核心（裁图+翻译+渲染）
│   ├── _sys_prompt_v2.txt     # 精读范式提示词（想改风格改这里）
│   ├── build_deepread_workflow.py  # 重建 n8n 工作流的脚本
│   └── archive/               # 迭代过程的旧版本（存档，可忽略）
├── docs/                      # 文档
├── workflow_data/            # 与 n8n 容器共享的数据目录
│   ├── input_pdf/            # （可选）手动放 PDF 的地方
│   ├── to_process/           # n8n 落地的待处理任务（自动）
│   ├── done/                 # 处理完的任务存档（自动）
│   ├── summary/             # ★ 精读结果 HTML 在这里
│   └── mineru_output/        # 一份解析结果样本
├── n8n_data/                 # n8n 内部数据（数据库、工作流）
└── wf_backup/                # 旧工作流备份
```

## 常见调整

- **换总结风格/范式**：改 `scripts/_sys_prompt_v2.txt` 里的提示词。
- **换模型**：改 `scripts/watcher.py` 顶部的 `MODEL`（默认 deepseek-v4-pro），或设环境变量 `DEEPREAD_MODEL`。切本地模型设 `DEEPREAD_PROVIDER=ollama`。
- **精读引擎在哪配 key**：`启动精读服务.bat` 里的 `DEEPSEEK_KEY`，或 `watcher.py` 顶部。

## ⚠️ 安全提醒（重要）

以下密钥在搭建调试中出现在了脚本/记录里，**建议全部重新生成一次**：
- DeepSeek API key（platform.deepseek.com）
- MineRU token（mineru.net）
- n8n API key（n8n 设置 → n8n API）

它们目前明文存在：`scripts/watcher.py`、`启动精读服务.bat`、n8n 的「设置Token」节点里。轮换后记得同步更新这几处。
