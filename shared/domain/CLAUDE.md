# domain · 纯逻辑环 —— 给 LLM 的说明

> 你可能是被单独选中这个文件夹打开的。本文件是你的全部上下文。

## 判据：什么东西该放这里

**只有「我们自己想法变了」才需要改的代码。** 外部世界怎么变都影响不到它。

论文正文怎么切成骨架、章节怎么归类、表格和数字怎么扫 —— 这些十年不变，
是架构准则【选型判据】判定为「自己做、要完全掌控」的部分。

反过来：**只要它会因为「某个 API 换版本了/某个模型换代了」而改，它就不属于这里，
属于 `adapters/`。**

## 三条禁令（`tests/test_architecture.py` 强制，违反了 pytest 立刻变红）

```
❌ 不许联网（urllib / requests / httpx / socket）
❌ 不许 import 数据库或外部服务客户端（chromadb、keyring），不许起子进程
❌ 不许 import `shared.kernel.paths`
```

**第三条最容易被忽略，但它才是关键**：domain 永远不知道文件放在哪，
路径一律由调用方传进来。一旦 domain 知道了 `data/` 的布局，
它就跟我们的数据组织方式绑死了 —— 既不能独立测试，也不能被复用，
而且改一次目录布局就会波及本该最稳定的一层。

## 现有成员

| 块 | 是什么 |
|---|---|
| `outline` | 一篇论文 → **稳定的骨架**（节 / 段 / 表 / 图注的地址、类别、字数）；`scan` 数数字与表格行；`props` 性能名归一与「数 + 单位」拆分 |

2026-10-24 收成这一块：原来的 `schema`（结构化抽取的字段表、提示词、出表）随抽取整套删了，
只剩骨架还在用的部分，改名 `outline`；`libmatch` / `numcheck` / `glossary` / `stopwords` 随精读、找文献一起删了。
`figure_crop` 搬进了它唯一的用户 `host/mcp/`。

## 为什么这一环值钱

它是唯一能**全离线、毫秒级**跑单元测试的一层。整个安全网的地基就在这里：
`domain` 越厚，能被快速验证的逻辑就越多，重构就越不吓人。
