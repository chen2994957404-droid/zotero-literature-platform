# cli · 命令行参数解析

> 你可能是被单独选中这个积木文件夹打开的，看不到项目其他部分。本文件是你的全部上下文。

## 这是什么

**一块「公理件」** —— 平台的最小可复用单元。本块的职责只有一件：**统一全项目取命令行参数的方式**。

2026-08-11 体检发现 79 个 .py 里有 97 处手写 `sys.argv`、风格至少 10 种。
本块存在的意义：让所有脚本的参数写法变成同一套，消灭「每看一个文件学一种写法」。

用户是材料方向研究者（聚硼硅氧烷/动态键弹性体），**不懂编程**。

## 对外接口

| 函数 | 用途 |
|---|---|
| `pos(i, default=None)` | 第 i 个位置参数（**位置参数必须在 `--` 选项之前**） |
| `flag(name, default=False)` | 开关：出现 `--名字` 即 True |
| `opt(name, default=None)` | 带值选项：`--名字 值` |
| `opts(name)` | 可重复选项：`--tag a --tag b` → `['a','b']` |
| `positionals()` | 全部位置参数（`--` 之前的部分） |

## 铁律

1. **取不到参数返回默认值，绝不抛异常** —— 缺参由脚本业务逻辑自己判断。
2. **不引入 argparse** —— 项目参数都很简单，argparse 的重装备用不上；
   这符合宪法判据「能自己做的稳定部分自己做」。
3. **本块只读 `sys.argv`，不 import 项目里任何东西** —— 它是被 import 顺序最靠前的块，
   加了依赖会把「标准开头」那套路径引导搞复杂。

## 谁在用它

所有需要命令行参数的脚本（随框架化迁移逐步接入）。**本块没有依赖，改动零风险。**
