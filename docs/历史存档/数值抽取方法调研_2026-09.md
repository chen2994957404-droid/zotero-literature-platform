## 一、这个问题在领域里叫什么（定义）

我们要做的是**文档级 N 元关系抽取**：一条记录 = 材料/样品 × 性质 × 数值+单位 × 条件。领域里有两套成形的任务定义：

- **MeasEval**（SemEval-2021 Task 8，[论文](https://aclanthology.org/2021.semeval-1.38/)，[数据](https://github.com/harperco/MeasEval)）：
  Quantity（数+单位+修饰）→ MeasuredProperty（测的什么性质）→ MeasuredEntity（测的什么东西）→ Qualifier（条件）。
  26 个用户、77 份有效提交。**数和单位最容易；把数连到被测对象 / 性质最难**：最好的队伍 HasQuantity 0.48、HasProperty 0.32、Qualifies 0.09。
- **PolyIE**（NAACL 2024，[论文](https://aclanthology.org/2024.naacl-long.131/)，[数据与代码](https://github.com/jerry3027/PolyIE)）：
  146 篇聚合物全文，领域专家标了材料 / 性质 / 数值 / 条件及其 N 元关系（4443 条）。难点：实体写法多样、实体之间有歧义、
  **一个性质可能描述一个或几个材料、不同性质在不同条件下测**。最好的是 PURE-SUM + MatSciBERT，N 元关系 F1 **63.89%**。

→ 我们在自己金标上看到的（数找得到 66%，挂错样品是最大的一块）**不是我们做得特别差，是这个任务公认的核心难点**。

## 二、已有路线（各自靠什么、到多少）

| 路线 | 代表工作 | 靠什么 | 效果（原文数字） | 依赖大模型？ |
|---|---|---|---|---|
| **规则 / 语法 + 小模型 NER + 依存句法配对** | ChemDataExtractor 2 应力–应变库（Sci. Data 2024，[PMC](https://pmc.ncbi.nlm.nih.gov/articles/PMC11585639/)） | SciBERT 认材料名；每个性质一套正则「标识词」；**DepIE：在依存句法图上按距离最小把性质词、数、单位、材料连起来**；表格单独解析 | 300 篇人工全抽作金标：总 P 82% / R 92% / F1 **87%**；**表格 F1 92%，正文 80%**（正文 P 74%） | 否（SciBERT 1 亿参数级） |
| **半监督模板学习** | Snowball 2.0（JCIM 2023，[PMC](https://pmc.ncbi.nlm.nih.gov/articles/PMC10685441/)） | 人标约 1250 句种子 → 按实体顺序与词袋相似度聚类成模板 → 带置信度套到新句 | 带隙：P 约 75–85%，R 约 65–75%；作者说 P 过不了 90% | **完全不依赖** |
| **训练专用小模型做关系抽取** | PolyIE 基线；MatSciBERT（npj Comput. Mater. 2022） | 在人工标注上训练 NER + 关系模型 | PolyIE N 元关系 F1 64%；有研究指出**任务专用微调模型在本体约束的 NER 上明显好于 GPT-4 上下文学习**（[PMC12116928](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC12116928/)） | 否 |
| **弱监督 / 数据编程** | Snorkel（[arXiv 1711.10160](https://arxiv.org/pdf/1711.10160)）；材料信息抽取的自动生成语料（Sci. Data 2022） | 规则、词典、别的模型都写成**带噪声的标注函数**，由统计模型合并成训练标签，再训练一个模型 —— **规则不再直接出结果，而是出训练数据** | 各任务不同（未精读，待补） | 否 |
| **大模型做老师、蒸馏给小模型** | 综述性结论（例：把前沿大模型的监督转给微调的 GLiNER 类小抽取器） | 大模型标一批 → 小模型学 → 之后只跑小模型 | 未精读具体数字，待补 | 只在造数据时用一次 |
| **大模型对话式抽取 + 自我核对** | ChatExtract（Nat. Commun. 2024，[原文](https://www.nature.com/articles/s41467-024-45914-8)） | 先判句子有没有数据 → 抽 → 追问核对 | P、R 都 **>90%**（最好的对话大模型） | **强依赖** |
| **大模型微调做联合抽取** | Dagdelen 等（Nat. Commun. 2024，[代码](https://github.com/lbnlp/NERRE)） | 微调 GPT-3 / Llama-2 直接出 JSON | 三个材料任务 | 依赖（7B 起） |
| **表格专门抽取** | MaTableGPT（Adv. Sci. 2025） | 表格表示 + 切分 + 追问滤幻觉 | 水分解催化文献表格 F1 最高 96.8% | 依赖 |

**跨路线的共同结论**：
1. **表格远比正文可靠**（应力–应变库：表格 F1 92% vs 正文 80%）→ 先吃表格，正文补充
2. **连线（数↔样品↔性质）才是核心难点**，数和单位本身用规则 / 语法就够（我们的找数已到 90%）
3. 不依赖大模型、而且**能随数据变好**的连线方法有三种：**依存句法距离**（DepIE）、**从种子学模板**（Snowball）、**训练专用小模型**（PURE / MatSciBERT，可用弱监督或大模型造训练数据）

## 三、对照我们现在的做法：哪里走偏了（判断）

- 我们用 4B 模型**逐题零样本判断**连线，再用手写规则补它的错 —— 这条路在文献里没有对应的成熟路线，也解释了为什么越补越像拟合：
  **规则直接产出结果**，每条规则只覆盖写它时看到的那几种句式。
- 文献里规则的正确用法是两种：① 写成**语法 / 依存句法层面的通用算法**（DepIE 不针对任何一篇的写法）；
  ② 写成**标注函数**，让统计模型合并、再训练一个会泛化的小模型（Snorkel 的思路）—— 规则的错会被别的规则和模型抵消，而不是一条条补。
- 评测：MeasEval / PolyIE 都是**按子任务分别计分**（数、单位、性质、对象、条件、各条关系），我们只有一个总分，看不出进步卡在哪一环。

## 四、建议的方法路线（判断，待用户定）

原则：**核心方法不依赖模型档次**；模型（若用）只做「造训练数据」或「一个可替换的零件」。

1. **任务定义对齐 MeasEval / PolyIE**：记录 = 数+单位（Quantity）· 性质（MeasuredProperty）· 样品（MeasuredEntity）· 条件（Qualifier）；
   金标补齐这四个字段，**按子任务分别计分**
2. **表格优先**：表格走结构解析（我们已有 `scan_tables`），单独在金标上计分；正文只补表格里没有的
3. **连线换成有出处的通用算法**：复现 DepIE 的依存句法距离配对（本地 spaCy / Stanza，CPU 可跑，不需要大模型），先在金标上和现在的 4B 方案对比
4. **把现有规则改造成标注函数**，在上千篇全文上生成弱标签（可以把本地 9.7B 也当作一个标注函数），训练一个 MatSciBERT 级的专用关系模型（约 1 亿参数，3060 显卡能训练 —— **待实测**）
5. **现成的聚合物标注数据先用起来**：PolyIE 有 146 篇聚合物全文的专家标注，可以直接当训练 / 评测数据（许可证待核实）
6. 评测纪律：考卷冻结、只报数；新考卷另选、标完不再读原文

**合理的期望**（据文献，判断）：正文连线 F1 0.7–0.8、表格 0.9 左右是好系统的水平；PolyIE 这类多材料多条件的聚合物文献，专用模型也只有 0.64。
