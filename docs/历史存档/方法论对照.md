# 各条流程对应的既有方法论（2026-09-14 查证）

用户原话：「这些确实还是得找专门的理论方法论这些来指导做。」
本表把平台的每条流程对到信息检索 / 系统综述 / 文献计量 / 科学文本处理里**已经定型**的方法，
并写明我们现在做到哪、差在哪。**只列查到出处的**；没查到的不写。

| 流程 | 既有方法（出处） | 我们现在 | 差距 / 可借的 |
|---|---|---|---|
| 找文献 · 检索策略 | 积木式 / 逐步收窄 / 滚珠式 / 交互扫描（Harter 1986；Meadow & Cochrane 1981；Markey & Cochrane 1981；Hawkins & Wagers 1982，综述见 [Marchionini 第 5 章](https://ils.unc.edu/~march/isee_book/Chapter_5.pdf)）；Bates 战术「永远质疑空集」 | `discover` 拆 5 条互补检索式 ≈ 积木式的一种；`lit_search` 给 total | 已写进 `deep-research` skill。`discover` 的提示词可以显式按「面」拆（每面 OR 同义词），而不是「五个角度」 |
| 找文献 · 雪球 | [Wohlin 2014 滚雪球指南](https://www.wohlin.eu/ease14.pdf)：起始集要多样（出版商 / 年份 / 作者、彼此不互引）、前后向都做、迭代到没有新文献 | `discover` 从库里挑 3 篇种子；新方向模式从命中里挑被引最多的 3 篇 | **起始集多样性没保证**（3 篇可能互引、同一作者）。可加：挑种子时避开互引与同一通讯作者；迭代直到无新增而不是只滚一轮 |
| 找文献 · 报告 | [PRISMA-S](https://www.equator-network.org/reporting-guidelines/prisma-s/)：16 项检索报告清单（用了哪些库、检索式原文、日期、限制、去重方法、各步数量） | 命令行打印检索式与各式贡献；没有留档 | 让 `discover` 把「检索式 / 来源 / 日期 / 各步数量 / 过滤条件」写成一份可回放的记录（PRISMA-S 的子集），报告附上 |
| 读一篇 · 分层读 | [Keshav 三遍读法](http://ccr.sigcomm.org/online/files/p83-keshavA.pdf)：第一遍标题摘要小标题结论（5–10 分钟）→ 第二遍读内容不读细节 → 第三遍复现 | 骨架 L0/L1/L2 正好对应；`library_outline` = 第一遍 | 一致。可在 skill 里明说：模型读一篇默认只做第一、二遍，第三遍（复现）是精读的事 |
| 读一篇 · 章节分类 | Teufel 的 [Argumentative Zoning](https://www.cl.cam.ac.uk/~sht25/az.html)（Background / Aim / Own / Basis / Contrast / Other / Textual；AZ-II 15 类）；**材料领域有现成数据集 [MuLMS-AZ](https://arxiv.org/pdf/2307.02340)**；[多学科标题结构分析](https://www.sciencedirect.com/science/article/abs/pii/S1751157718304942) | 九类按标题关键词 + 位置判 | 我们的类别是「节」级、AZ 是「句」级。真正有用的一条：AZ 的 **Other / Basis**（别人的结果 vs 自己的）—— 正是金标里「把引言里别人的数当成本文的」那个错。MuLMS-AZ 可以拿来评我们的分类，或训一个小模型做句级标注 |
| 抽数值 · 结构化抽取 | [ChemDataExtractor](https://pubs.acs.org/doi/full/10.1021/acs.jcim.6b00207)（规则 + NER，表格 / 图注 / 段落各有文法；F 0.87–0.93）；[聚合物属性抽取流水线](https://www.nature.com/articles/s41524-023-01003-w)（MaterialsBERT，13 万摘要 → 30 万条记录）；[通用 LLM 抽取](https://arxiv.org/pdf/2302.04914) | 脚本扒表格（1051/1063 条带出处）+ 拆段问模型 + 金标 27%→91% | 方向一致（**表格用规则、正文用模型**）。可借：ChemDataExtractor 对「表格 / 图注 / 段落」**分别写文法**的做法 —— 我们图注还没抽数；MaterialsBERT 那类领域 NER 可作本地小模型的候选 |
| 问答 · 检索粒度 | Parent-document / small-to-big 检索（[综述](https://futureagi.com/glossary/parent-document-retriever/)；[HiChunk 基准](https://arxiv.org/pdf/2509.11552)）：用小块检索、返回父节上下文 | 800 字块检索；`library_retrieve` 回段地址 → `section` 取父节 | 已是 small-to-big 的形状。差一步：`ask` 组装上下文时仍用小块，可改为「命中块 → 所在段 / 节」再喂模型 |
| 问答 · 评估 | RAGAS 的 faithfulness（答案里每条声明能否在检索到的片段里找到支持）等指标 | 有精读金标；问答没有评估 | 建一小组问答金标（问题 → 应命中的 id + 节），量 命中率 与 忠实度 |
| 横向比较 · 对比表 | [Webster & Watson 2002 概念矩阵](https://web.njit.edu/~egan/Writing_A_Literature_Review.pdf)：概念为行 / 文献为列，按概念综合，不按文献罗列 | `compare.md` 是「文献为行、字段为列」 | 转置一份「机理 × 性能」的概念矩阵就是 W&W 的形状；`direction` 找空白格用它 |
| 找方向 · 版图 | 文献计量的**文献耦合**（Kessler 1963，看研究前沿）与**共被引**（Small 1973，看知识基础），[两者比较](https://www.researchgate.net/publication/220433193_Co-Citation_Analysis_Bibliographic_Coupling_and_Direct_Citation_Which_Citation_Approach_Represents_the_Research_Front_Most_Accurately) | `direction` 用引用网络聚类 | 明确用哪种耦合：找**前沿**用文献耦合，找**根**用共被引；现在没区分 |
| 找方向 · 空白类型 | [Miles 2017 七类研究空白](https://www.researchgate.net/publication/319244623_ARTICLE_Research_Methods_and_Strategies_Workshop_A_Taxonomy_of_Research_Gaps_Identifying_and_Defining_the_Seven_Research_Gaps)：证据 / 知识 / 实践-知识冲突 / 方法 / 经验 / 理论 / 人群 | 「机理 × 性能」空格 = 只有「知识空白」一种 | 报告里把空白按类型标：**证据冲突**（两篇结论相反）和**方法空白**（都用同一种测法）在材料领域很常见，现在完全看不见 |

## 下一步建议（按投入产出）

1. **雪球起始集多样性**（Wohlin）：小改 `discover` 挑种子的规则，立刻生效
2. **检索留档**（PRISMA-S 子集）：`discover` 跑完落一份 json，报告可回放
3. **空白分类**（Miles）：`direction` / 报告模板加「空白类型」一栏
4. **概念矩阵**（W&W）：从 paperdb 生成一份「机理 × 性能」转置表
5. **句级 Other/Basis 标注**（AZ / MuLMS-AZ）：投入大，先做评估再决定
