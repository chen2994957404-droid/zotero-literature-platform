# 项目结构导览 · 这个项目由什么组成

> 给**人**读的地图：打开任何一个文件夹都知道「这是干嘛的」。
> 相关的几份：`README.md` 怎么用 · `各部分的关系.md` 这件事该动哪个文件夹 ·
> `AGENTS.md` 给 AI 的正本 · `HANDOVER.md` 做到哪了（自动生成）。
>
> 2026-10-23 重写：平台收成两样东西之后，旧版（精读 / 抽取 / 找文献时代）整份过时了，旧版在 git 历史里。

---

## 一、一句话看懂整体

```
取原件（getpdf） → 落地加工（ingest：解析 → 骨架 → 向量化） → 给 Claude Science 读（/science 接口）
                                                          → 给你查（文献库应用）
```

平台只管两样：**原件**（正文 PDF + SI）和**加工到最适合 AI 读的数据**。
读文献、找新文献、比数值、读曲线，都交给 Claude Science。

代码按「**什么会让它需要改**」分五层，依赖只能从上往下（`tests/test_architecture.py` 守着）：

| 层 | 是什么 | 什么会让它改 |
|---|---|---|
| `shared/kernel/` | 地基：路径、配置、日志、目录卡、状态库、心跳、预算 | 几乎不会改 |
| `shared/domain/` | 纯逻辑：只剩 `schema`（全文 → 骨架、表格与数字扫描） | 只有我们自己想法变了 |
| `shared/adapters/` | 对外接口：MineRU、取全文、向量库、OpenAlex / Crossref、各网页库 | **外部世界变了** |
| `tools/` | 两个工具：`library`（查库、骨架、按节读、向量检索）· `getpdf`（取原件） | 需求一变就变 |
| `host/` | 平台自身：文献库应用、控制面板、体检、部署、看门狗、落地流水线、MCP 接口 | 运维方式变了 |

---

## 二、`tools/`

| 工具 | 干什么 | 花钱吗 |
|---|---|---|
| `library` | 有没有这篇、按条件检索、研究团队、专题、骨架、按节读原文、向量检索、建向量库（`vectorize.py`）| 不花 |
| `getpdf` | 给 DOI → 借真实浏览器用学校订阅取正文 + SI → 落进证据库 | 不花钱，但整批会触发出版商风控，只给人点 |

## 三、`host/`

| 块 | 干什么 |
|---|---|
| `app/` | **文献库应用**（桌面「文献库」）：检索、团队、专题、打开 PDF / SI |
| `mcp/` | MCP 协议层；`science.py` 是给 Claude Science 的 `/science` 接口（还带 SciFinder、知网、CCDC、JCR、Scopus、PoLyInfo、试剂价格等网页库）；`figure_crop/` 按版面裁整图；`prompts/` 读提示词文件 |
| `ingest/` | **落地流水线**：有正本没解析的 → MineRU 解析 → 骨架 → 向量化；`proc_lock/` 保证同一时刻只有一份在跑 |
| `watcher/` | **看门狗**：守落地流水线（`AUTO_BUILD=1` 才拉）和三个端口服务（8780 应用 / 8778 MCP / 9333 取全文浏览器）|
| `panel/` | 控制面板：落地处理进度、密钥与本机设置、运行状态与日志 |
| `doctor/` | 一键体检、诊断报告、产物缺口 |
| `deploy/` | 拉新代码 + 装包 + 重启；编程机隧道任务 |
| `codegen/` | 生成器：`HANDOVER.md`、`.claude/`、坑的总目录 |

## 四、`data/`（不进版本库，权威副本在主力机）

| 层 | 放什么 | 丢了怎么办 |
|---|---|---|
| `raw/<id>/` | `main.pdf` · `si.*` 原件；`parsed/` · `si_parsed/` 解析结果（`full.md`、`images/`、`layout.json`）| 原件丢了要重新下；解析结果可重跑 MineRU |
| `curated/<id>/` | `meta.json` 目录卡 · `outline.json` 骨架 · `figures/` 整图 | 目录卡要重新登记；骨架和整图零成本重算 |
| `serving/` | `vector_db/` 向量库 · `oa_index.json` 作者摘要索引 · `team_links.json` | 都可重建 |
| `state/` | `teams.json` 研究团队名单（**人工，不可重建**）· `topics.db` 专题 · `state.db` 处理记录 | 名单和专题丢了就没了 |
| `logs/` | 运行日志 | 不要紧 |

## 五、其他文件夹

| 文件夹 | 是什么 |
|---|---|
| `launch/` | 双击就能跑的 `.bat`，文件名就是按钮名 |
| `docs/` | `explain/` 为什么 · `howto/` 怎么做 · `reference/` 事实 · `incidents/` 坑 · `历史存档/` 已删功能的旧文档 |
| `tests/` | 跨工具的结构守卫（各块自己的测试跟着各块住）|
| `toolbox/` | 跟文献无关的通用工具：远程操作另一台机器、拆分工具的锻造间 |
| `outputs/` `scratch/` | 外部 agent 的产物 / 草稿，不进版本库 |
| `.claude/` | 给 AI 的运行时配置，**全部自动生成，别手改** |
