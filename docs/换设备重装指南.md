# 换设备重装指南 · Reinstall Guide

> 换新电脑时，照着这份从零复现整套"文献图文精读闭环"系统。预计 1-2 小时（含下载）。
> 每一步都标注了**为什么**，以及对应的踩坑（详见 `踩坑记录.md`）。

---

## 一、前置软件安装

| 软件 | 用途 | 备注 |
|------|------|------|
| **Docker Desktop** | 跑 n8n 容器 | 装完在设置里开"开机自启" |
| **Python 3.11+** | 跑所有精读脚本 | 勾选 "Add to PATH" |
| **Ollama** | 本地模型（向量化/短任务） | 精读本身不用，但保留 |
| **Zotero 7** | 文献库（数据源+闭环入口） | 登录你的账号 |

Python 装完后装依赖：
```
pip install pymupdf
```
（`pymupdf` = 裁图用的 PyMuPDF，唯一的第三方依赖。其余都是标准库。）

---

## 二、拷贝项目文件

把整个 `n8n-literature-workflow` 文件夹拷到新电脑（可以放任意路径，比如 `D:\...\n8n-literature-workflow`）。

**注意路径变化**：以下文件里有**硬编码路径**，换机后要改：
- `scripts/zotero_watcher.py` 顶部的 `STORAGE_DIR`（Zotero 的 storage 目录，见第四步确认）
- 各 `.bat` 启动脚本里的路径（如果项目放的位置变了）
- `启动精读服务.bat` / `启动Zotero闭环.bat` 里的 `OLLAMA_MODELS` 路径

---

## 三、配置密钥（重要）

所有 key 集中在 `启动Zotero闭环.bat` 顶部，换机后填新的：
```bat
set DEEPSEEK_KEY=<你的DeepSeek key>
set MINERU_TOKEN=<你的MineRU token>
set ZOTERO_API_KEY=<你的Zotero Web API key>
```
- DeepSeek key：platform.deepseek.com
- MineRU token：mineru.net
- Zotero API key：zotero.org/settings/keys（勾选 write access + notes）

n8n 那条链（可选）的 key 在 n8n 界面的「设置Token」节点里，以及 `scripts/build_deepread_workflow.py` 命令行参数。

---

## 四、Zotero 配置确认

1. 打开 Zotero，登录账号，等文献库同步下来。
2. **开启本地 API**：设置 → 高级 → 勾选允许本地 API（配置项 `extensions.zotero.httpServer.localAPI.enabled` 应为 true）。
3. **确认 storage 路径和 user id**：
   ```
   # 查 user id（填进 zotero_watcher.py 的 USER_ID）
   curl -H "Zotero-Allowed-Request: true" "http://localhost:23119/api/users/0/items/top?limit=1"
   # 返回里的 library.id 就是 user id
   ```
   storage 目录一般在 Zotero 数据目录下的 `storage\`，把它填进 `zotero_watcher.py` 的 `STORAGE_DIR`。

---

## 五、部署 n8n（可选，仅"处理不在Zotero里的文献"时用）

```
cd 项目目录
docker compose up -d
```
`docker-compose.yml` 已含必要配置（`NODE_FUNCTION_ALLOW_BUILTIN=fs,path` 等，这是踩坑6的解法，别删）。

导入工作流：n8n 起来后，跑
```
python scripts\build_deepread_workflow.py <n8n_api_key> <mineru_token> <deepseek_key>
```
（n8n API key 在 n8n 界面 设置→n8n API 里生成。）

---

## 六、Ollama 模型（可选）

```
setx OLLAMA_MODELS "<你的模型目录>"
ollama pull bge-m3        # 向量化模型（做向量库时用）
ollama pull qwen3:8b      # 短任务用
```
踩坑4提醒：`OLLAMA_MODELS` 一定要指对，否则 Ollama 找不到模型。

---

## 七、启动与自启

**手动启动**：双击 `启动Zotero闭环.bat`（前提 Zotero 和 Docker 开着）。

**设置开机自启**（PowerShell 跑一次）：
```powershell
$bat="<项目目录>\启动Zotero闭环.bat"
$startup=[Environment]::GetFolderPath('Startup')
$ws=New-Object -ComObject WScript.Shell
$s=$ws.CreateShortcut("$startup\Zotero精读闭环.lnk")
$s.TargetPath=$bat; $s.WorkingDirectory="<项目目录>"; $s.WindowStyle=7; $s.Save()
```

---

## 八、验证

1. 在 Zotero 里给一篇有 PDF 的文献打标签 `待精读`。
2. 等几分钟，看 `workflow_data\summary\` 出现 `<标题>_精读.html`。
3. 看 Zotero（同步后）该文献下多了精读笔记，标签变 `已精读`。
4. 看 `workflow_data\logs\zotero_watcher.log` 有处理记录。

全通过 = 复现成功。

## 依赖清单速查

- Python 库：`pymupdf`（其余标准库）
- 外部服务：DeepSeek API、MineRU API、Zotero（本地API + Web API）
- 容器：n8n（仅可选路径用）
- 关键文件：`scripts/zotero_watcher.py`（闭环主控）、`scripts/mineru_parse.py`（解析）、`scripts/deepread_v4.py`（裁图+精读）、`scripts/_sys_prompt_v2.txt`（精读范式）
