# 积木采购清单 · 可借鉴/可拿来的开源积木

> 目的：把前人做好的积木盘点清楚，用来①优化现有公理件 ②补齐后面要用的。
> 原则（第一性原理）：公理层应用最可靠、最经验证的实现，不重复造轮子。
> 但也守宪法——拿来的东西要保持"可理解、可自测、纯粹"，不引入厚框架负担。

---

## 一、优化现有积木

### pdf_parse（现用 MineRU）→ 结论：保持，不用换
前沿科研 PDF 解析主流就是 MinerU / Marker / Docling / GROBID。对标发现：
- **Docling** 缺 bounding box——而我们的裁图依赖坐标，换了会坏裁图。
- **Marker** 慢 1000 倍、要 GPU（53s/页）——不划算。
- **MineRU**（我们在用）：有坐标、有免费额度、够快。→ **选择正确，保持。**
- **GROBID**：精确定位表格/公式强，但**不能处理图**。若将来表格数据提取要求变高，
  可了解它作补充；现在没必要。

## 二、后面要用的新积木（按研究价值排序）

### ★ 优先级1：图表数字化 pipelines/chart_digitize（计划）
- **用途**：把论文图里的曲线/散点提取成数据点（X-Y 数值）。直接解决"定量数据收集"痛点
  ——能把别人论文图里的数据抠出来变成你能用的数值。
- **可拿来**：
  - **PlotPick**（2026，开源，视觉模型批量提取，超越专用 chart-to-table 模型）
    https://plotpick.streamlit.app/ ，论文 arXiv:2605.06021
  - **Engauge Digitizer**（经典离线开源，支持线性/对数/极坐标，导出 CSV）
  - **ChartReader**（端到端，OpenCV，GitHub Cvrane/ChartReader）
- **形态**：独立公理件（输入图片→输出数据点+坐标校准）。不塞进精读（宪法·单一职责）。

### ★ 优先级2：化学/材料实体抽取 modules/chem_extract（计划）
- **用途**：从化学文献抽材料名/性质/数值/单位。补 LLM 抽取的短板——
  LLM 会有脏数据（踩坑#13），而专用工具对"材料名、性质、单位"更可靠。
- **可拿来**：**ChemDataExtractor2**（剑桥团队，**MIT 许可可自由用**，精度 92.2%，
  含化学 NER + 规则解析 + 表格解析）GitHub CambridgeMolecularEngineering/chemdataextractor2
- **用法**：作为 LLM 抽取的**交叉验证/补充**（两者对照，提高数值可信度）。
- **注意**：Python 3.9–3.11（我们环境要确认兼容）。

### ★ 优先级3：文献发现/引用网络 pipelines/paper_discovery（计划）
- **用途**：给一篇文献→找语义相似的、找引用它的、找它引用的。
  让平台从"处理已有库"扩展到"发现该读的新文献"。
- **可拿来**：**Semantic Scholar API**（官方，含 Recommendations API）+
  非官方 Python 库 `semanticscholar`（typed/分页/异步）。
  参考 allenai/citeomatic（引用推荐）、alperenkocyigit/semantic-scholar-graph-api（现成 MCP）
- **形态**：独立公理件（输入 DOI/标题→输出相关文献列表）。

### 优先级4（远期）：知识图谱 modules/knowledge_graph（构想）
- **用途**：把"材料—结构—性能—工艺"抽成节点+关系连成网，支撑"找研究空白/idea"。
  这是"找 idea"从平表升级到关系网的方向（前沿在做，如 MatKG 7万实体540万关系）。
- **参考**：不急拿来，先了解方法（层次化分块优于固定分块——我们的 hierarchical_body 已对）。
- **形态**：是"定理/工作流"层，建立在 chem_extract 等公理件之上，地基稳后再做。

## 三、取用原则（守宪法）

1. **能优化现有的先优化**（如需要时用 GROBID 补表格），能拿来的独立公理件按需拿来。
2. 拿来的第三方库，**包一层我们自己的公理件接口**（modules/<件>/），
   对外暴露干净接口 + README + selftest——这样底层换库，上层不动（数据契约思想）。
3. **不引入厚框架**（对标报告结论）：拿"能力"，不拿"抽象负担"。保持可理解性。
4. licensing 要看：ChemDataExtractor2 是 MIT（可自由用）；其他逐个确认。
