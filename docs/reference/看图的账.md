# 看图（图表数字化）的账 —— 实测，不是估的

> 2026-09-07 在主力机上真跑出来的数。**下次要改这份，也请去跑一次再改。**

## 用量（实测 3 张，模型 `deepseek-v4-flash-vision-exp`）

| | 每张图 |
|---|---|
| 输入 | 约 716 token |
| 输出 | 约 11159 token |

**输出是输入的 15 倍** —— 因为它吐的是一串串坐标点。所以这条线的成本几乎全在输出侧，
「把图压小一点」省不到钱，**「少读几张图」才省钱**。

## 单价（DeepSeek 官方定价页，2026-09-07 查）

`deepseek-v4-flash-vision-exp` 与 `deepseek-v4-flash` 同价（美元 / 百万 token）：

| | 低谷时段 | 高峰时段 |
|---|---|---|
| 输入（未命中缓存）| 0.22 | 0.44 |
| 输出 | 0.66 | 1.32 |

> 高峰 = UTC 周一至周五 01:00–04:00 与 06:00–10:00，其余都是低谷。

## 全库估算（42 篇 = 292 张图）

输入约 21 万 token、输出约 326 万 token：

| | 低谷 | 高峰 |
|---|---|---|
| 合计 | **约 2.2 美元** | **约 4.4 美元** |

**结论：全抠一遍是十几到三十几元人民币的量级，不是大钱。**
真正该省的不是钱，是**别读那些根本读不出数的图**（见下）。

## 命中率（实测 5 张里 2 张白花）

按图注关键词挑的 5 张里，有 2 张是 `multi_panel`（SAXS/WAXS 图谱、多联排版），
模型读回 0 条曲线 —— 钱花了，什么也没得到。

所以下一步不是"全抠"，而是**先把挑图的判据做准**：
排除示意图/SEM/TEM/XRD/NMR/光谱，只留应力应变、模量、效率随循环数这类**真曲线**。
