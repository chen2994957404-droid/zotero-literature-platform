# 两台机器的分工

> 立于 2026-08-26，2026-10-24 按「平台只管原件 + 给 Claude Science 读的数据」重写
> （旧版写的是 Zotero、精读、抽取那个年代，在 git 历史里）。
> **任何 LLM 接手前先读这份** —— 它决定了「你现在在哪台机器上、什么能做什么不能做」。

---

## 零、一句话

**A 机 = 编程端（改代码的唯一入口）· B 机 = 运行端（数据与服务的唯一权威）。**

代码单向从 A 流向 B（走 git）；数据只在 B 上长，A 机只放几篇样本做回归。

---

## 一、两台机器是什么

| | A · 编程端 | B · 运行端（主力机） |
|---|---|---|
| Claude Code | **只在这里** | 没有 |
| `data/` | 几篇测试样本 | **权威副本**：原件、解析结果、目录卡、骨架、向量库、团队名单、专题 |
| 常驻服务 | 不跑（例外：`LiteraturePlatformTunnel`，只往外连的 SSH 隧道）| 看门狗（任务名 `ZoteroLiteratureWatcher` 是历史遗留）守 8780 文献库应用 / 8778 MCP / 9333 取全文浏览器；`OllamaService` |
| 机构订阅 IP | 不一定 | 有（取全文、各网页库都靠它）|

为什么这么分：订阅权限认的是 B 的出口 IP；取全文的浏览器里有人过过人机验证；
向量库和 Ollama 在 B 上；数据只有一份权威副本，才不会两边各长各的。

---

## 二、谁干什么（有争议时以本表为准）

| 事项 | A 编程端 | B 运行端 |
|---|---|---|
| 改代码 / 写测试 / 架构守卫 | ✅ **唯一入口** | ❌ 绝不在 B 上改 |
| `pytest` + 离线档体检 | ✅ 每次改动 | 上线时跑一次 |
| 完整档体检 | 可跑（几项红是正常的） | ✅ **权威结论以 B 为准** |
| 取全文（`getpdf`）、查各网页库 | ❌ 没有订阅 IP、没有那个浏览器 | ✅ |
| 落地流水线（解析 → 骨架 → 向量化）| 测试档可以对样本跑 | ✅ |
| 常驻服务 / 自启任务 | ❌ **绝不注册**（隧道除外）| ✅ **唯一** |
| 控制面板、文献库应用 | 开发调试时开 | ✅ **用户日常入口** |

---

## 三、代码怎么从 A 到 B

A 机提交、推送 → `python toolbox/remote-machine/remote.py deploy`（拉代码 + 装包 + 重启）→ `remote.py logs` 核对。

⚠ **部署不等于换文件**：常驻进程在代码被换掉后照跑旧的。`deploy` 会重启它知道的服务；
端口服务（8780 / 8778）拿不准时，按端口停掉，看门狗一分钟内用新代码拉起来。

⚠ **SSH 会话读不到 Windows 凭据库**：要密钥的作业（MineRU 解析、OpenAlex 取索引）
从 A 机远程发起时，走 `remote.py job "..."`，别用 `run`。连机器的细节在全局技能 `remote-machine`。

---

## 四、B 的状态怎么让 Claude 看见

用户在 B 机跟前只有一个动作：**双击**。所以诊断类的东西都并进 `host/doctor/report.py`
（`launch/不常用/诊断报告.bat`），一次给全；A 机上的 Claude 直接 `remote.py run` / `logs` 去看，
**别让用户敲命令**（双击 .py 窗口一闪而过，他什么也看不到 —— 真实发生过）。

## 五、机器角色（`ROLE`）

写在每台机器的本机设置里（控制面板「本机设置 → 机器角色」），代码里由 `shared/kernel/role.py` 执行：

| 角色 | 给谁 | 允许什么 |
|---|---|---|
| `dev` | 编程端默认（没设也按它算，最安全）| 不许跑常驻服务、全库作业、花钱的批量 |
| `test` | 编程端测试档（A 机现在是这档）| 允许跑，产物只落在本机 |
| `prod` | 主力机 | 全部 |

有副作用的入口（常驻服务、整批作业）在**函数体里**调 `role.require_prod(...)`，
写在模块顶层会让 `import` 就抛错（体检和 pytest 收集会一起挂）。守卫在 `tests/test_architecture.py`。

---

## 六、给接手 LLM 的检查清单

1. 我在哪台机器上？（`python -c "from shared.kernel import role; print(role.current())"`）
2. 这件事要不要机构 IP / 那个浏览器 / 凭据库里的密钥？要 → 在 B 上做，远程走 `job`。
3. 改完代码了？先 A 机 `pytest` + 离线体检全绿，再部署，部署完核对日志里的启动时间。
